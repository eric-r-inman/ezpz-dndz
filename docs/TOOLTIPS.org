#+title:     Tooltip Review
#+language:  en
#+startup:   showall

Every UI tooltip (~title~ HTML attribute) the project surfaces, grouped
by where it appears.  Each entry lists:

- *id* — the constant name in [[file:../frontend/src/View/Tooltips.elm][~View.Tooltips~]] you edit to change it.
- *attached to* — the UI affordance that shows the tooltip on hover.
- *current text* — the string the user sees today.
- *call site* — the view module + line that imports the constant
  (clickable from VS Code).

To reword a tooltip:

1. Find the entry below.
2. Edit the matching constant in
   [[file:../frontend/src/View/Tooltips.elm][~frontend/src/View/Tooltips.elm~]].
3. Run ~elm make~ — every reference is checked at compile time, so
   you can't drop a tooltip by accident.

Dynamic tooltips (XP scope, condition chip, timer, etc.) live at the
bottom of the module as small helpers; their entries here include
the format template plus the values that get interpolated.
